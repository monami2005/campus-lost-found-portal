# Contributing Guidelines

Thank you for considering contributing to the **Campus Lost & Found Portal** project!

## How to Contribute

1. **Fork the Repository**: Create a personal fork of the repository on GitHub.
2. **Clone your Fork**:
   ```bash
   git clone https://github.com/YOUR-USERNAME/campus-lost-found-portal.git
   cd campus-lost-found-portal
   ```
3. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/amazing-feature
   ```
4. **Make Changes & Test**:
   Run automated test suite:
   ```bash
   php vendor/phpunit/phpunit/phpunit
   ```
5. **Commit & Push**:
   ```bash
   git commit -m "Add amazing feature"
   git push origin feature/amazing-feature
   ```
6. **Open a Pull Request**: Submit a Pull Request targeting the `main` branch.

## Code Standards
- Adhere to PSR-12 coding standard.
- Include unit/feature tests for new functionality.
